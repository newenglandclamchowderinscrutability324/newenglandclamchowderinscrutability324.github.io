## 🛡️ Using Policy Filtering

You can prevent sensitive information from being sent to AI providers. The tool checks your prompts against a list of blocked terms.

To add a blocked term:
1.  Type "filter add [term]"
2.  Replace [term] with the word you want to block.
3.  The software automatically skips any prompt that contains this word.

## 📝 Logging Your Prompts
